# AppCDS — кэширование преобразованных классов без повторного разбора

*Русский. Английский оригинал: [`../en/appcds.md`](../en/appcds.md).*

Модуль: [`aetherium-loader`](../../aetherium-loader) (`AppCdsManager`).

Повторный прогон конвейера ASM (`ClassReader` → дерево → `COMPUTE_FRAMES` → проверка
`CheckClassAdapter`) для каждого изменённого класса при **каждом** запуске — доминирующая стоимость фазы
загрузки. Aetherium устраняет её между запусками двумя слоями.

## Слой 1 — memory-mapped архив преобразованных классов (активен)

Итоговые байты каждого изменённого класса сохраняются в blob с ключом
`имя + FNV-1a(исходных байт)`. При следующем запуске blob отображается в память (через FFM
`MappedRegion`), и **попадание возвращает кэшированные байты одним копированием среза — весь конвейер ASM
пропускается**.

```
запуск #1: холодный промах → ASM-трансформация → record(имя, hash, преобразованные байты) → flush
запуск #2: mmap blob → lookup(имя, исходные байты) → ПОПАДАНИЕ → возврат байт (ноль разбора ASM)
обновление MC/NeoForge меняет класс → меняется его hash → автоинвалидация записи (промах → перекэш)
```

Ключ-хэш означает, что обновление NeoForge или Minecraft инвалидирует **только** устаревшие записи, а не
весь кэш. Менеджер безопасен по построению: любая I/O-ошибка отключает кэш на запуск (все промахи, лог
один раз) и никогда не бросает в путь трансформации. Сброс — при завершении JVM.

## Слой 2 — подсказки запуска для JVM AppCDS (`.jsa`)

`AppCdsManager` также пишет список классов и точные флаги JVM, чтобы запускающий слой включил собственный
Application Class-Data Sharing JDK — позволяя JVM отобразить *разобранные, проверенные* метаданные классов
всего пространства и обойти даже разбор classfile:

```
-XX:+AutoCreateSharedArchive
-XX:SharedArchiveFile=<cacheDir>/aetherium.jsa
-XX:SharedClassListFile=<cacheDir>/aetherium-appcds.classlist
```

Слой 1 убирает стоимость ASM Aetherium; слой 2 — собственную стоимость разбора classfile у JVM. Вместе
они делают «тёплый» запуск почти мгновенным.

## Конфигурация и инспекция

- Включено по умолчанию; `-Daetherium.cds.enabled=false` для отключения.
- Каталог кэша: `${user.dir}/.aetherium/cds`, переопределение `-Daetherium.cds.dir=<путь>`.
- `aetherium cdscache` показывает статус (записи, размер архива, счётчики hit/miss/store).
- `aetherium cdscache test` запускает round-trip самотест: холодный промах → запись + flush →
  **переоткрытие (mmap) → тёплое попадание (ноль разбора ASM)** → инвалидация устаревших байт.
