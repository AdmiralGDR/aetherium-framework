# LSP-бэкенд — автодополнение для IDE и предсказание конфликтов до компиляции

*Русский. Английская версия: [`../en/lsp.md`](../en/lsp.md).*

CLI Aetherium заодно работает как бэкенд **Language Server Protocol** (`org.aetherium.cli.lsp`). Он даёт
IDE две вещи, которые мод-разработчик иначе узнаёт лишь после неудачной сборки: реальное проверенное
**автодополнение точек инъекции** для ванильных методов Minecraft и **предсказание конфликтов хуков** тем
же DAG-движком, что у загрузчика — *до* компиляции.

## Транспорт

`AetheriumLspServer` говорит на базовом протоколе LSP — JSON-RPC 2.0 с обрамлением `Content-Length` по
stdio — на основе крошечного читателя/писателя JSON без зависимостей (`Json`), сохраняя офлайн-подход.
Битый кадр даёт ответ parse-error, а не валит сервер.

```bash
aetherium lsp --serve     # настоящий Language Server по stdio (подключите IDE)
aetherium lsp             # вместо этого запустить самотест бэкенда
```

## Автодополнение: валидные точки инъекции

`VanillaMethodIndex` — кураторский, независимый от загрузчика каталог часто-инъецируемых ванильных
методов: JVM-имена + дескрипторы + валидные для каждого якоря (`HEAD`, `RETURN`), без импортов Minecraft.
Бэкенд отвечает на `textDocument/completion` (нечёткое совпадение префикса) и расширение Aetherium
`aetherium/injectionPoints` (все цели класса) элементами автодополнения LSP, поэтому IDE может предложить
`net.minecraft.world.entity.Entity::tick` и подсказать подходящие якоря. В реальном развёртывании
дополняется из маппленного jar Minecraft; кураторский набор делает функцию полезной офлайн.

## Предсказание конфликтов (главное)

`aetherium/predictConflicts` берёт хуки, разобранные IDE из исходника/DSL мода, и прогоняет
`ConflictPredictor`. Важно: порядок проверяется **настоящим** `LiveHookGraph` → `HookDag`
([`injector.md`](injector.md)), поэтому предсказанное «OK» совпадает с рантайм-вплетением. Сообщает:

- **`ordering-cycle`** (ошибка) — настоящий цикл `runBefore`/`runAfter` внутри группы привязки.
- **`duplicate-id`** (ошибка) — два хука с одинаковым id.
- **`invalid-anchor`** (предупреждение) — якорь, недопустимый для известной ванильной цели.
- **`competing-cancel`** (предупреждение) — несколько отменяющих хуков на одном якоре; семантический
  слиятель композирует их (все выполняются; последняя отмена задаёт возврат), но порядок стоит проверить.

Каждая находка возвращается как диагностика в форме LSP (`severity`, `code`, `message`, `relatedHooks`).

## Доказательство

```bash
aetherium lsp
```

Самотест подтверждает, что автодополнение выдаёт реальные ванильные цели, предиктор ловит цикл порядка и
конкурирующие отмены, пропуская чистый набор, а полный обрамлённый JSON-RPC `initialize` проходит
туда-обратно через транспорт.
