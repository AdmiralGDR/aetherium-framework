# Delta-Sync — сеть на основе битовой карты изменений

*Русский. Английская версия: [`../en/delta-sync.md`](../../en/explanation/delta-sync.md).*

Delta-sync улучшает zero-GC синхронизацию `StructArena` ([`network.md`](network.md)), передавая **только
изменённые за последний тик строки** — не весь буфер.

## Битовая карта изменений

`DirtyBitmap` — один бит на строку сущности, упакованный в слова `long`. Производитель помечает строку
грязной при её изменении. Ключевая операция — `forEachRun`, объединяющая подряд идущие грязные строки в
непрерывные пробеги `(startRow, rowCount)` — поэтому кодек отправляет каждый пробег одним zero-copy
off-heap `writeSegment`, а не построчно и не весь буфер. Сама битовая карта крошечная на проводе (один бит
на строку), поэтому передаётся целиком, а получатель детерминированно восстанавливает те же пробеги.

## Вычисление дельты

`StructArenaDelta` держит ограниченную **off-heap тень** последнего переданного образа. После того как
`AetheriumTickEngine` продвинул сущности, `computeDirty(arena, rowCount)` сравнивает каждую строку с тенью
(`MemorySegment.mismatch`), записывает изменённые строки в `DirtyBitmap` и обновляет тень. Первый вызов
помечает все строки грязными (начальное полное состояние отправляется один раз). Диф тысяч сущностей не
аллоцирует в куче Java.

## Формат провода

`StructArenaDeltaCodec` кодирует `[rowCount][bitmapWordCount][words…][грязные пробеги]`:

- **Кодирование:** записать число строк и слова битовой карты, затем стримить каждый непрерывный грязный
  пробег, нарезанный прямо из серверной арены (`segment().asSlice(...)`).
- **Декодирование:** прочитать битовую карту, восстановить те же пробеги и читать каждый прямо в
  соответствующий срез предвыделенной клиентской арены — поэтому нетронутые строки сохраняют прежние
  значения, и пишутся только грязные байты.

Обе стороны без аллокаций в куче Java. `StructArenaDeltaPacket` несёт арену, число строк и битовую карту
и сообщает `payloadBytes()` против `fullBytes()` для экономии.

## Доказательство

```bash
aetherium delta
```

При 4096 сущностях тик, двигающий **7** строк, отправляет **112 байт** вместо **65 536** — побайтовое
восстановление клиента.
