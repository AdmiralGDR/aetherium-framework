# Внутриигровая проверка и анализ модов

`aetherium-verify` — рантайм-компаньон Щита: позволяет игроку (или админу) **проверять и анализировать
загруженные моды прямо в игре** — какие моды есть, кто их подписал и совпадает ли их байткод с тем, что было
собрано.

## На что отвечает

Для каждого загруженного `AetheriumMod` `ModInspector.snapshot(ClassLoader)` строит `ModReport`:

| Поле | Значение |
|---|---|
| `modId` | идентификатор мода |
| `author` | автор из **водяного знака** Щита (`""`, если не подписан) |
| `verdict` | `SIGNED_INTACT` / `TAMPERED` / `UNSIGNED` |
| `classesChecked` | сколько классов атрибутировано моду (точка входа + объявленный контент) |
| `tamperedClasses` | классы, чьи байты не совпадают с манифестом целостности |
| `contentCount` | декларативные `@AetheriumBlock`/`@AetheriumItem` |
| `nativeGuard` | активен ли нативный (Zig) гард как бэкенд контрольной суммы |

Вердикт даёт `ModVerifier` (в `aetherium-shield`): сливает все `META-INF/aetherium/shield-integrity.txt` на
classpath и пере-хеширует байты каждого класса (SHA-256). Несовпадение = класс **правили после защиты** —
взломанный jar, внедрённый бэкдор или обойдённая проверка.

## Как использовать в игре

Загрузчик регистрирует встроенную команду:

```
/aetherium mods       # список модов с вердиктом, автором, числом классов и контента (в чат)
/aetherium verify     # сводка целостности; называет TAMPERED-моды (уровень 2)
/aetherium inspect    # (клиент) открывает прокручиваемый экран-инспектор
```

`/aetherium inspect` открывает `AetheriumModInspectorScreen` — прокручиваемый список с точными метриками
шрифта, отрисованный через настоящий UI-адаптер загрузчика (см. [ui](ui.md)); подделанные моды — красным.
Так как экран — чистый `AetheriumScreen`, весь инспектор раскладывается и hit-тестится **без игры** в
`ModVerifySelfTest` (`aetherium verify`).

## Принуждение (сильное по умолчанию)

Загрузчик запускает `ModVerifier` при инициализации и по умолчанию **отказывается инициализировать
подделанный мод**:

```
Aetherium REFUSES tampered mod 'x' — its bytes do not match the Shield integrity manifest.
```

`-Daetherium.shield.enforce=false` — режим только-отчёт (инспектор всё равно подсветит красным, мод
загрузится). Неподписанные моды (без манифеста) не затрагиваются. Отладчик/агент показывается отдельно
нативным гардом (см. [shield](shield.md)) — эвристика, поэтому сообщается, а не жёстко принуждается.

## Почему это суверенно

Верификатор зависит только от самого фреймворка: манифест целостности Щита, чистый UI-модуль и
без-зависимостный нативный гард Zig для быстрой нативной контрольной суммы (с откатом на чистый Java). Ни
внешней библиотеки, ни сервиса — фреймворк проверяет свои моды, в своём рантайме, на экране. `aetherium
verify` — офлайн-доказательство, `aetherium guard` — статус нативного гарда.
